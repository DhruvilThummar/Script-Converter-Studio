🧬 What is TOON?

Token-Oriented Object Notation is a data serialization format designed for human readability and ease of use. It aims to be more intuitive than JSON for certain types of data, particularly configurations and hierarchical information.

Core Principles

  • Readability First: Syntax is minimal and clean, resembling a simple text file.
  • Indentation-Based Hierarchy: Nested objects are defined by indentation, like Python or YAML.
  • Key-Value Pairs: Uses a colon (`:`) to separate keys and values.

Tabular Arrays

TOON has special syntax for lists of objects, making them compact and easy to read, similar to a CSV file. This is a key feature that distinguishes it from JSON. 

users[2]:
id,   name,   role
101,  Alice,  Admin
102,  Bob,    User

Simple Syntax

For simple key-value data, the syntax is extremely straightforward.

name: Project Hermes
version: 1.0.0
is_active: true

Nested Objects

Indentation is used to represent nested data structures clearly.

database:
  host: localhost
  port: 5432
  user: admin

JSON vs. TOON

JSON (JavaScript Object Notation)

A lightweight data-interchange format that is easy for humans to read and write and easy for machines to parse and generate. It is based on a subset of the JavaScript Programming Language, Standard ECMA-262 3rd Edition - December 1999.

{
  "name": "Project Hermes",
  "version": "1.0.0",
  "is_active": true,
  "database": {
    "host": "localhost",
    "port": 5432,
    "user": "admin"
  }
}

TOON (Token-Oriented Object Notation)

A human-friendly data serialization format. It is designed to be easy to read and write, and its syntax is more concise than JSON for certain types of data. It is ideal for configuration files and other situations where human readability is a top priority.

name: Project Hermes
version: 1.0.0
is_active: true
database:
  host: localhost
  port: 5432
  user: admin

Frequently Asked Questions

What is the main advantage of TOON over JSON?

TOON's main advantage is its readability. Its syntax is cleaner and more concise than JSON's, making it easier for humans to read and write. This is especially true for configuration files and other data that is primarily meant for human consumption.

Is TOON a replacement for JSON?

No, TOON is not a replacement for JSON. JSON is a well-established standard with broad support across many programming languages and platforms. TOON is a newer format that is designed for specific use cases where human readability is a top priority. For machine-to-machine communication, JSON is still the better choice in most cases.
