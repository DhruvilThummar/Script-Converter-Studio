🧬 What is TOON?

Token-Oriented Object Notation is a data serialization format designed for human readability and ease of use. It aims to be more intuitive than JSON for certain types of data, particularly configurations and hierarchical information.

Core Principles

  • Readability First: Syntax is minimal and clean, resembling a simple text file.
  • Indentation-Based Hierarchy: Nested objects are defined by indentation, like Python or YAML.
  • Key-Value Pairs: Uses a colon (`:`) to separate keys and values.

Tabular Arrays

TOON has special syntax for lists of objects, making them compact and easy to read, similar to a CSV file. This is a key feature that distinguishes it from JSON. 

users[2]:
id,   name,   role
101,  Alice,  Admin
102,  Bob,    User

Simple Syntax

For simple key-value data, the syntax is extremely straightforward.

name: Project Hermes
version: 1.0.0
is_active: true

Nested Objects

Indentation is used to represent nested data structures clearly.

database:
  host: localhost
  port: 5432
  user: admin
